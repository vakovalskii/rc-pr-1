# rc-pr-1 — телеуправляемая RC-багги с выносом вычислений по сети

Переделка HW8808RD (1:16) со сломанного штатного управления на свою платформу.
Борт тонкий — камера, ШИМ и failsafe; всё остальное считается по сети.

## Стенд: петля замыкается без железа

```
машинка ──WS /ws/car──► relay.py ◄──WS /ws/pult── браузер телефона
```

Машинка подключается **исходящим** соединением — поэтому CGNAT оператора
не мешает, внутрь стучаться не нужно.

```bash
python3 relay.py                              # терминал 1, слушает :8080
python3 fake_car.py                           # терминал 2, синтетическая сцена
open http://<ip-мака>:8080                    # пульт
```

## Езда по своей съёмке

```bash
python3 prep_video.py дом.mov data/dom --fps 4   # нарезка + отбраковка смаза
python3 video_car.py --frames data/dom/frames    # вместо fake_car.py
```

Газ ведёт вдоль отснятого маршрута, руль поворачивает взгляд — окно
кадрирования едет внутри широкого кадра. `--zoom` задаёт запас на поворот.

## Запись датасета для имитационного обучения

```bash
curl "localhost:8080/rec/start?name=zal"      # поехали
curl  localhost:8080/rec/stop
```

Кладётся в `datasets/<имя>/`: `frames/000001.jpg` плюс `log.jsonl` со строками
`{i, t, steer, throttle, speed, pos, yaw}`. Формат как у DonkeyCar — кадр и
команда, которая его вызвала.

## Как снимать дом

1. **Камера на высоте машинки, 10–15 см от пола** — главное правило. Вид с
   роста человека и вид с пола не сматчатся между собой.
2. Идти медленно и плавно, 0.3–0.5 м/с. Смаз убивает восстановление поз.
3. Замкнуть петлю — вернуться в точку старта.
4. Несколько проходов под разными углами, не один прямой проезд.
5. Ровный свет, не против окна. Экспозиция и фокус зафиксированы (долгий тап).
6. Одно фокусное на весь ролик, сверхширик не брать.
7. Избегать зеркал, стекла, глянца, белых стен, людей и котов.
8. 4K 30 к/с, 2–5 минут на комнату.

## Замеры

| что | значение |
|---|---|
| RTT петли (браузер → релей → машинка → обратно) | **36 мс** |
| MJPEG VGA 15 к/с | 1 Мбит/с ≈ 450 МБ/час |

В поле сверху лягут кодирование и LTE — ждём 150–350 мс. Вывод: софт в задержке
почти не участвует, бюджет съест сеть.

## Грабли

- `websockets` подхватывает системный `HTTPS_PROXY` даже на localhost —
  в `connect()` обязателен `proxy=None`, иначе HTTP 502.
- Failsafe: нет команд 500 мс → газ в ноль. Есть в симуляторе, уедет в прошивку
  без изменений. Для машинки, уезжающей за пределы видимости, это не опция.
