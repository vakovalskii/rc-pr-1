# Эксперимент по удалённому управлению электронной машинкой 1/16

Переделка RC-багги HW8808RD (1:16) со сломанного штатного управления на свою
платформу. Борт тонкий — камера, ШИМ и failsafe; всё остальное считается по сети.
Цель — гонять по полю рядом с домом и учиться работать с картами и самоходными
штуками через удалённые нейронки, замеряя скорость петли.

Железо, что есть и что покупаем — в [docs/BOM.md](docs/BOM.md).

## Что уже работает без единой железки

```
машинка ──WS /ws/car──► relay.py ◄──WS /ws/pult── браузер телефона / автопилот
   │                        │
   │ fake_car.py            └── datasets/<имя>/  кадр + команда (формат DonkeyCar)
   │ video_car.py   езда по кадрам твоей съёмки
   └ polygon_car.py свободная езда по карте, собранной из съёмки
```

Машинка подключается к релею **исходящим** соединением, поэтому CGNAT
оператора не мешает: внутрь стучаться не нужно.

```bash
uv sync                                   # .venv с torch (MPS), opencv, scipy
python3 stand.py start                    # релей + синтетический симулятор
python3 stand.py start --car polygon --data data/synth
python3 stand.py status                   # адрес пульта для телефона
python3 stand.py stop
```

Пульт: `http://<ip-мака>:8080` — газ левым пальцем, руль правым, HUD с RTT и
потоком, минимапа с положением машинки. Карта на весь экран: `/map.html`.

## Конвейер: съёмка → карта → полигон → обучение → автопилот

| шаг | команда | что даёт |
|---|---|---|
| 1. кадры | `prep_video.py дом.mov data/dom --fps 4` | нарезка + отбраковка смазанных |
| 2. позы | `recon.py data/dom --cam-height 0.12` | COLMAP → позы в метрах, пол z=0, **вердикт: годная / переснять** |
| 3. карта | `map_build.py data/dom` | сетка занятости `map/map.png`, план для глаз `map_view.png` |
| 4. полигон | `stand.py start --car polygon --data data/dom` | свободная езда с столкновениями; картинка — ближайший кадр съёмки |
| 5. датасет | `stand.py rec start zal` … `rec stop` или `auto_drive.py data/dom --laps 8 --noise 0.45 --record zal` | пары кадр → команда; эксперт пишет чистую метку при возмущениях |
| 6. обучение | `train_bc.py datasets/zal --epochs 20` | `models/bc.pt`, поведенческое клонирование |
| 7. автопилот | `pilot.py --seconds 60 --reset` | едет сам, печатает пробег и удары |

Все скрипты запускать через `.venv/bin/python` (или `uv run`).

## Как снимать дом

1. **Камера на высоте машинки, 10–15 см от пола** — главное правило. Вид с
   роста человека и вид с пола не сматчатся между собой.
2. Идти медленно и плавно, 0.3–0.5 м/с. Смаз убивает восстановление поз.
3. Замкнуть петлю — вернуться в точку старта.
4. Несколько проходов под разными углами, не один прямой проезд.
5. Ровный свет, не против окна. Экспозиция и фокус зафиксированы (долгий тап).
6. Одно фокусное на весь ролик, сверхширик не брать.
7. Избегать зеркал, стекла, глянца, белых стен, людей и котов.
8. 4K 30 к/с, 2–5 минут на комнату. Заодно **измерить длину пройденного
   маршрута** шагами — `recon.py --path-length 12` задаёт масштаб надёжнее пола.

## Замеры

| что | значение |
|---|---|
| RTT петли (браузер → релей → машинка → обратно) | **36 мс** |
| MJPEG VGA 15 к/с | 1 Мбит/с ≈ 450 МБ/час |
| инференс политики на M1 Pro (MPS) | единицы мс на кадр |

В поле сверху лягут кодирование и LTE — ждём 150–350 мс. Вывод: софт в задержке
почти не участвует, бюджет съест сеть. Отсюда два контура: быстрый 20 Гц на
борту (курс, failsafe), медленный 0.5–2 Гц удалённо (VLM ставит цели, не рулит).

## Грабли

- `websockets` и `urllib` подхватывают системный `HTTPS_PROXY` даже на localhost —
  в коде везде `proxy=None` / `ProxyHandler({})`, иначе HTTP 502.
- **COLMAP: только модели камеры с одним фокусом** (SIMPLE_RADIAL, SIMPLE_PINHOLE).
  При съёмке на постоянной высоте без наклонов PINHOLE/OPENCV не могут оценить
  fy и сплющивают мир по вертикали в разы (на синтетике — в 8 раз).
- Пол под острым углом почти не реконструируется. Уровень пола берётся как
  самый нижний плотный слой точек — низ стен и мебели; ещё надёжнее `--path-length`.
- Сеть на голых ReLU без нормализации входа временами стартует мёртвой и
  выдаёт константу до конца обучения. BatchNorm + вход в [-1, 1] лечит.
- Руль: `+1` = вправо во всех машинках, пульте и эксперте. Метка эксперта
  при возмущениях (`--noise`) — чистая команда, а не исполненная.
- Failsafe: нет команд 500 мс → газ в ноль. Есть во всех симуляторах, уедет в
  прошивку без изменений.
- Колмап из brew ломается при обновлении abseil (`Library not loaded: libabsl_…`):
  `brew upgrade re2`.
